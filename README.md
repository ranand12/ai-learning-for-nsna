# AI learning for NSNA

Slide decks for **AI From Zero**, a 4-week beginner GenAI training series. Each deck is a single self-contained HTML file.

| Deck | File |
|---|---|
| Week 1 · Fundamentals | [week1-fundamentals.html](week1-fundamentals.html) |
| Week 2 · Use AI Better | [week2-use-better.html](week2-use-better.html) |

## Presenting

Open a file in a browser.

- → / Space / click: next (reveals the answer on question slides first)
- ← / click the left third: back
- **N**: speaker notes · **F**: fullscreen · Home / End: first / last slide
- `#12` at the end of the URL jumps to slide 12
